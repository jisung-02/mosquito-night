# 잠들 수 없는 밤

실사풍 침실 전체에서 모기를 잡아 코인을 모으고, 장비와 작은 생태계를 키우는 Godot 게임입니다. 상점은 필요할 때만 열립니다.

## 웹 버전

난이도는 생존한 밤마다 증가합니다. 첫 밤은 모기 2마리로 시작하고 최대 5마리까지 등장하며, 다음 밤부터 출현 빈도·속도·빠른 모기 비율이 올라가고 잡기까지의 시간이 짧아집니다. 각 밤의 첫 12초는 적응 구간이고 이후 60초까지 압박이 서서히 올라갑니다. 12단계에서 상승을 제한해 끝없이 빨라지지 않으며, 실패하면 같은 밤에 재도전합니다. 코인·구매 내역은 유지합니다. 선풍기는 바람이 닿는 범위의 비행과 물림 시간을 늦춥니다. 왕모기 유충 사육통은 제거되었으며 기존 구매 비용은 저장 버전 3으로 이전하면서 한 번만 환불됩니다. 3번째 밤부터 경계형, 5번째 밤부터 두 번 타격해야 잡히는 끈질긴 모기가 소량 등장합니다. 전기모기채와 자동 포획 장치는 한 번에 잡습니다.

GitHub Pages 배포 주소: https://jisung-02.github.io/mosquito-night/

게임이 브라우저 창 전체를 채우며 시작 버튼·Space/Enter에서 전체화면으로 전환합니다. 브라우저의 입력 허용 시점에 소리가 시작되고, F 또는 Esc로 전체화면을 전환할 수 있습니다. 웹의 코인·구매 기록은 해당 브라우저에 별도로 저장됩니다.

게임 소스 저장소는 [jisung-02/mosquito-night](https://github.com/jisung-02/mosquito-night)입니다. [페이지 저장소](https://github.com/jisung-02/jisung-02.github.io)는 `games/mosquito-night` Git submodule로 게임의 특정 커밋을 지정합니다. Pages 배포는 submodule을 함께 가져와 Godot 4.7.2로 게임을 빌드한 뒤 Astro 사이트에 포함합니다. 생성된 WebAssembly·PCK 파일은 페이지 저장소에서 추적하지 않습니다.

Web 내보내기는 단일 스레드로 설정해 GitHub Pages에 추가 응답 헤더 없이 실행됩니다. `python3 tools/export_web.py --output ../web-build/mosquito-night`로 웹 파일과 라이선스를 생성합니다. Godot이 PATH에 없으면 `--godot /Applications/Godot.app/Contents/MacOS/Godot`을 추가하세요. `build.json`에 실제 게임 커밋·엔진 버전·PCK 체크섬이 기록됩니다.

페이지 저장소를 처음 받을 때는 `git clone --recurse-submodules git@github.com:jisung-02/jisung-02.github.io.git`을 사용하세요. 이미 받은 저장소에서는 `git submodule update --init --recursive`로 지정 버전을 복원합니다. 게임을 수정하면 게임 저장소에 먼저 커밋·push한 뒤, 페이지 저장소의 submodule 커밋을 갱신하고 배포합니다. `git submodule update --remote games/mosquito-night`는 게임의 최신 main을 가져오며, 부모 저장소에 변경된 포인터를 커밋해야 배포 버전이 바뀝니다.

웹 글꼴은 OFL Noto Sans KR를 보통 굵기로 고정하고 실제 UI 문자만 포함한 Night Korean입니다. 새로운 한글 문구를 추가하면 `tools/build_web_font.py`를 fonttools가 설치된 Python에서 실행한 뒤 다시 내보내세요. 원본은 `tools/fonts/NotoSansKR.ttf`, 라이선스는 `assets/fonts/OFL.txt`입니다. PC 버전은 기존 시스템 글꼴을 사용합니다.

## 실행과 조작

앱을 열면 손뼉·도구 조작, 코인과 자동 사냥, 생존 목표를 짧게 안내합니다. 시작 버튼 또는 Space/Enter로 시작하며, 안내 중에는 모기·시간·물림·자동 사냥이 멈춥니다. 시작 클릭이 공격으로 이어지지 않고 다음 밤과 다시 시작에는 안내를 반복하지 않습니다.

플레이.command를 더블클릭하거나 Godot에서 project.godot을 열고 F5를 누르세요. 전체화면으로 시작합니다.

- 마우스 이동 / 왼쪽 클릭: 두 손 또는 도구 조준 / 손뼉 치기·잡기
- 1 / 2 / 3: 손뼉 / 구입한 신문지 / 구입한 전기모기채 장착
- B 또는 오른쪽 위 '상점 B': 상점 열기 / 닫기
- 상점의 구매·강화 버튼 클릭: 코인으로 구매. 상점에서는 시간이 멈춥니다.
- P: 일시정지 / 계속. 다른 앱으로 이동하면 자동으로 일시정지합니다.
- M: 음소거
- H: 판정 영역 표시 / 숨기기. 밝은 초록색은 휘두르기의 유효 구간, 흐린 윤곽은 준비·복귀 중인 공격 면, 주황색은 모기의 몸통·날개입니다.
- R: 현재 밤 다시 시작. 보유 코인과 구매한 장비는 유지됩니다.
- Esc: 상점 닫기. 상점 밖에서는 전체화면 전환.
- F: 전체화면 전환
- 밤 종료 후 클릭 / Space: 생존했으면 다음 밤, 실패했으면 같은 밤 재도전

밤마다 60초 동안 버팁니다. 다섯 번 물리면 그 밤은 끝납니다. 잡은 점수만큼 코인도 쌓이며, 구매하면 보유 코인만 줄고 점수는 유지됩니다. 기본 모기는 10점, 황금 모기는 30점, 경계형은 20점, 끈질긴 모기는 25점. 수동 연속 포획은 최대 4배 점수입니다. 자동 포획도 점수와 코인을 줍니다.

## 상점

처음에는 맨손으로 시작합니다. **말아 쥔 신문지(40코인) → 전기모기채(80코인) → 자동 사냥 장비·동료** 순으로 구매가 열립니다. 도구 강화는 말아 쥔 신문지를 사면 열립니다. 신문지나 전기모기채를 사면 자동으로 장착되며, 1·2·3 키로 보유한 도구를 바꿀 수 있습니다. 손뼉은 타원 반경 약 23×29 / 간격 0.32초, 신문지는 약 14×47 / 간격 0.22초입니다. 손뼉은 둥근 근거리 판정이고, 신문지는 긴 종이 면에만 닿으므로 위아래로 멀리 닿지만 옆으로는 더 좁습니다. 전기모기채는 레벨당 범위 +12, 간격 -0.03초로 1단계 간격은 0.15초입니다. 범위는 1280×720 내부 화면 좌표 기준입니다.

| 장비 / 동료 | 첫 가격 | 역할 | 최대 단계 |
|---|---:|---|---:|
| 말아 쥔 신문지 | 40 | 길고 좁은 노출된 종이 면으로 타격. 더 빠른 첫 도구. 다음 구매 단계 개방 | 1 |
| 전기모기채 | 80 | 레벨당 범위 +12, 재사용 시간 -0.03초. 새 금속·카본 소재 모기채와 방전 효과 | 3 |
| 도구 강화 | 60 | 레벨당 긴 쪽 반경 +8, 신문지·전기모기채 그림과 판정 함께 증가 | 4 |
| 흡입식 포충기 | 130 | 책상에 설치. 기본 5초마다 반경 360 안의 모기 포획 | 3 |
| 파리지옥 | 100 | 협탁에 배치. 잎 가까이에 온 모기를 덫을 닫아 포획. 기본 대기 6초 | 3 |
| 끈끈이주걱 | 170 | 창틀에 배치. 잎 가까이에 붙은 모기를 잎을 말아 포획. 기본 대기 8초, 최대 두 마리 | 3 |
| 잠자리 동료 | 220 | 방을 순찰하며 모기를 직접 추격해 포획. 기본 대기 3.5초 | 3 |
| 선풍기 | 150 | 기존 책상 위 선풍기 가동. 바람 범위의 비행·물림 속도 감소 | 3 |

다음 강화 가격은 첫 가격 × 다음 레벨입니다. 포충기와 식물은 강화할수록 간격이 짧아지고 범위가 늘어납니다. 잠자리는 강화할수록 더 빠르게 날고 포획 간격이 줄어듭니다. 선풍기는 신문지 단계부터 구매할 수 있으며 강화할수록 바람의 감속 효과가 커집니다.

설치한 물건은 방 안에 나타납니다. 식물은 모기를 잎으로 유도하며 실제 포획은 해당 잎에서 20 + 3×레벨 픽셀 이내일 때만 일어납니다. 닫힌 잎은 5.5초 동안 다른 모기를 잡지 못하고, 다른 잎은 독립적으로 움직입니다. 흡입·식물 포획 시 모기가 장비 쪽으로 이동하는 효과가 나오고, 잠자리는 실제로 목표 모기까지 날아갑니다. 자동 사냥은 게임 실행 중이며 밤이 진행되는 동안 작동합니다. 일시정지와 상점, 밤 종료 상태에서는 멈춥니다.

## 움직임

- 모기: 몸통과 다리·날개를 나누어 움직입니다. 날개는 빠른 잔상을 유지하고 다리는 미세하게 흔들립니다. 잡히면 잠깐 떨어진 뒤 사라집니다.
- 손뼉: 두 손이 서로 마주 닫혔다 벌어지고 손가락이 조금 움직입니다. 두 손바닥이 만나는 순간 한 번 판정합니다.
- 신문지·전기모기채: 손목·손잡이를 중심으로 뒤로 준비한 뒤 빠르게 앞으로 휘두르고, 지나친 만큼 천천히 돌아옵니다. 도구 전체를 늘이지 않으며 신문지의 노출된 종이만 준비·복귀 때 작게 휘어집니다. 클릭 위치와 기울기는 해당 타격 동안 고정하고, 실제 움직이는 타격 면과 판정에 같은 변환을 씁니다. 잔상은 빠른 전진 구간에만 나타납니다.
- 잠자리: 네 날개와 몸통·다리를 분리했습니다. 추격할 때 가속하고 도착 전에 감속합니다. 선회 속도를 제한하고 작은 기울기를 넣었습니다.
- 식물: 화분은 고정하고 잎만 흔들립니다. 파리지옥은 약 0.3초에 걸쳐 덫을 닫고, 끈끈이주걱은 더 천천히 잎을 맙니다. 재개방은 게임을 위한 몇 초의 연출이며 실제 식물의 소화 시간을 재현하지 않습니다.
- 포충기·선풍기: 포충기는 팬 잔상과 흡입 입자를 사용합니다. 선풍기는 배경에 이미 놓인 모델을 가동하며 구입·강화에 따라 회전과 소리가 달라집니다.
- 방: 커튼 상단과 가구는 고정하고 커튼 아래쪽에 약한 바람 변형을 적용했습니다. 배경 팬에도 작은 회전 잔상을 더했습니다.

모든 움직임은 2D 이미지의 부분 변형·분리 렌더링과 비행 계산으로 구현했습니다. 상점·일시정지·밤 종료 시 배경과 포획 동작도 함께 멈춥니다.

## 저장

게임 제목 변경 후에도 이전 버전의 저장 위치를 계속 사용해 보유 코인과 구매 내역을 유지합니다.

사용자 데이터 폴더의 progression.json에 보유 코인, 장비 레벨, 장착한 도구, 밤 번호, 최고 기록이 저장됩니다. 구매·도구 변경 직후, 2초마다, 밤 종료, 정상 종료 때 저장합니다. 예전 best.json이 있으면 첫 실행에서 최고 기록을 옮기고, 그 기록만큼 코인을 한 번 지급합니다. 기존 장비가 있는 이전 버전 저장은 필요한 일반·전기모기채를 함께 보존해 구매 단계가 막히지 않습니다. 기록이나 코인을 초기화하지 않습니다.

## 소리

맨손은 두 손이 닫히는 0.075초 시점에 포획을 판정하고 실제 손뼉 녹음, 전기 포획은 실제 전기 스파크 녹음을 사용합니다. 빈 곳에 손뼉을 쳐도 손뼉 소리는 나며 점수는 주지 않습니다. 전기모기채가 빗나가면 방전 소리와 불꽃은 나오지 않습니다. 신문지는 종이 바스락과 짧고 둔탁한 종이 타격 소리, 포충기는 실제 작은 팬 녹음과 흡입 소리를 사용합니다. 식물은 작은 잎 마찰·끈끈한 접촉, 잠자리는 낮은 날개 마찰로 구분합니다. 식물·잠자리 소리는 게임에 맞춘 원본 폴리 합성입니다.

효과음마다 세 가지 변주를 두고, 모기·기기 위치에 따라 좌우로 들리게 했습니다. 모기 비행 소리는 가까운 개체를 따라 움직이며, 멀면 작게 들립니다. 일시정지·상점·밤 종료·음소거 상태에서는 환경음이 멈춥니다. M은 이미 재생 중인 효과음도 바로 끕니다. 녹음 출처와 편집 내역은 [오디오 크레딧](assets/audio/CREDITS.md)에 있습니다.

## 타격 판정

손뼉은 두 손바닥 사이의 영역에서 접촉 순간 한 번만 판정하며, 클릭 직후에는 잡히지 않습니다. 접근하는 동안 도망친 모기는 피할 수 있습니다. 손바닥 사이·신문지의 노출된 종이·전기모기채 그물은 각기 다른 비율의 타원형 판정을 사용합니다. 신문지의 판정은 중심으로부터 가로 약 14px·세로 47px이며, 손뼉은 가로 약 23px·세로 29px입니다. 신문지의 잡고 있는 손과 팔은 판정에서 제외합니다. 손가락 끝·손목·모기채 손잡이와 이미지의 투명한 여백은 공격 면에 포함하지 않습니다. 모기 표적은 몸통·머리·날개 영역을 합친 형태이며 화면에 보이는 크기와 회전을 따라 변합니다. 아주 얇은 다리와 긴 주둥이는 표적에서 제외합니다. 가장자리의 흐릿한 픽셀을 겨냥해도 과도하게 빗나가지 않도록 모기 윤곽에 내부 화면 좌표 기준 2px 여유를 줍니다.

신문지·전기모기채는 전체 휘두르기 시간의 25–40%에 해당하는 전진 구간에서만 판정합니다. 32% 시점에는 타격 면이 원래 겨냥한 위치를 통과합니다. 준비와 되돌아오기에는 포획되지 않습니다. 휘두르는 소리는 전진 시작에, 종이 타격음·방전음과 불꽃은 실제 접촉에 맞춰 한 번 발생합니다. 모기 이동과 타격 계산을 최대 1/120초 간격으로 함께 처리해 빠른 강화 도구도 낮은 화면 주사율에서 유효 구간을 건너뛰지 않습니다. 공격 중 장비 교체를 막고, 상점이나 일시정지 중에는 진행 중인 동작과 판정도 멈춥니다.

모기 중심점이 그물 밖에 있어도 몸통이나 날개 일부가 공격 면과 겹치면 잡힙니다. 렌더링과 충돌 계산은 같은 피벗·크기·회전 정보를 사용하며, 강화하면 그물 이미지와 판정 면이 함께 커집니다. 클릭할 때의 위치를 고정해 타격 중 마우스를 움직여도 해당 타격이 새 위치로 옮겨가지 않습니다. 전기 스파크도 겹친 지점에 나타납니다. 클릭 좌표는 입력 이벤트에서 읽고, 상점·일시정지·밤 종료 상태의 타격을 차단합니다. 화면 비율에 따른 늘어남은 그림과 판정에 동일하게 적용됩니다.

H는 확인용 윤곽선을 켜며 별도의 화면이나 패널을 열지 않습니다. 기본적으로 꺼져 있습니다.

## 리서치와 게임적 해석

- [UF/IFAS — Southern house mosquito](https://ask.ifas.ufl.edu/publication/IN837): 집모기류 Culex quinquefasciatus의 몸길이는 약 3.96–4.25mm입니다. 화면에서는 식별과 조준이 가능하도록 원근을 과장하되, 기존 120px 이미지 영역을 42–70px로 줄였습니다. 이는 다리까지 포함한 이미지 영역이며 실제 몸길이와 같지 않습니다. 가까운 개체는 조금 크고 먼 개체는 작게 보이며, 크기는 천천히 변합니다. 타격 판정은 몸통·날개의 크기를 따라 바뀌며 가장자리에 작은 여유를 줍니다.
- [Nature — Smart wing rotation and trailing-edge vortices enable high frequency mosquito flight](https://www.nature.com/articles/nature21727): 연구된 모기의 날갯짓은 초당 수백 회에 달합니다. 화면 주사율로 이를 그대로 재생하면 깜빡임이나 느린 역회전처럼 보일 수 있어, 여러 날개 위치를 겹친 반투명 잔상으로 표현했습니다. 날개와 몸통이 같은 가슴 부위를 중심으로 함께 움직입니다. 이는 관찰 영상의 인상을 살린 표현이며 공기역학 시뮬레이션은 아닙니다.
- [Craig Reynolds — Wander](https://www.red3d.com/cwr/steer/Wander.html): 이전 방향에서 조금씩 변하는 연속적인 선회 원리를 참고했습니다. 순항, 잠깐의 정지 비행, 짧은 급가속을 섞고 가속도에 제한을 둡니다. 벽 근처에서는 미리 방향을 바꾸며, 모기채를 휘두를 때 가까운 개체는 회피합니다. 몸통은 옆으로 이동할 때 살짝 기울고 매번 진행 방향으로 빙글 돌지 않습니다. 내부 계산 간격을 작게 나눠 화면 주사율에 따른 차이도 줄였습니다.
- [T-Minus 5 — FlySwatAR 개발 사례](https://tminus5.dev/portfolio/flyswatar): 유사한 벌레 잡기 게임은 애니메이션된 3D 곤충, 회피 AI, 자체 충돌 판정, 비행 궤적 입자와 공간 음향을 사용합니다. 현재 게임은 2D 침실 구도를 유지하므로, 이 중 자연스러운 비행·회피와 별도의 타격 판정 개념을 활용했습니다. 같은 엔진이나 동일 알고리즘을 사용한 것은 아닙니다.
- [Smithsonian Gardens — Dragonflies](https://gardens.si.edu/exhibitions/traveling/habitat/dragonflies/): 잠자리의 포식 습성을 자동 추격 동료로 반영했습니다.
- [RHS — 식충식물 재배 안내](https://www.rhs.org.uk/plants/types/carnivorous/growing-guide): 파리지옥의 닫히는 덫과 끈끈이주걱의 끈끈한 잎을 서로 다른 자동 포획 장비로 표현했습니다.
- [CDC — Integrated Methods of Mosquito Management](https://wwwnc.cdc.gov/eid/article/7/1/70-0017_article): 단순 자외선 전기 포충기에는 현실의 모기 방제 한계가 있습니다. 게임은 흡입 장치로 표현하고, 포획 속도와 유효 범위는 플레이를 위한 설정으로 조정했습니다.

현재 구현은 2D입니다. 배경, 모기, 손, 모기채, 장비·동료 소재는 imagegen으로 제작한 실사풍 이미지입니다. 모기 날갯짓·회전과 자동 포획 효과는 Godot에서 처리합니다. 잠자리는 날개를 제외한 몸통 이미지를 새로 만들고, 원본의 네 날개를 따로 추출해 가슴에 붙여 움직입니다. 경계형 모기는 기존 모기의 자세·비율·투명 배경을 유지하면서 검은 몸체와 옅은 줄무늬를 추가한 내장 imagegen 편집 결과입니다. 프롬프트는 assets/mosquito_cautious_prompt.md, 소재는 assets/mosquito_cautious.png에 저장되어 있습니다. 선풍기 상점 이미지는 배경의 해당 부분을 AtlasTexture로 사용합니다. 새 손 이미지의 제작 프롬프트는 '밤 침실의 달빛에 맞춘 사실적인 오른손 손바닥, 다섯 손가락, 엄지는 보는 쪽 왼편, 손목은 아래, 투명 배경'입니다. 모든 게임 소재는 assets/에 포함되어 있습니다. 외부 사진이나 3D 모델을 재배포하지 않습니다. 소리에는 위 크레딧의 CC0 녹음을 사용합니다.

`godot --windowed --path . --script res://verify.gd -- --verify-game`

테스트 전용 저장 경로를 사용해 실제 기록과 구입 상태를 건드리지 않습니다. 맨손 시작, 구매 단계 제한, 도구 장착·저장·이전 저장 이전, 접촉 때만 방전, 빗나간 소리, 음소거, 장비별 효과음, 재화 차감, 잔액 부족·최대 강화 거부, 강화 범위, 자동 사냥, 상점 시간 정지, 물림과 다음 밤 장비 유지 등을 검증하고 손·게임·상점 미리보기를 저장합니다.

`godot --headless --path . --script res://verify_hit_geometry.gd`

몸통·날개의 일부 겹침, 빈 이미지 모서리·다리 끝·손잡이·손목 제외, 크기·회전별 경계 판정, 강화 이미지와 판정 크기 일치, 접촉 스파크 위치와 좌표 변환을 검증합니다.

`godot --headless --path . --script res://verify_motion.gd`

화분 고정, 손바닥·모기 몸통 판정 위치 보존, 잎·손가락·다리·꼬리의 독립 변형, 잠자리 가속·선회·기울기 제한과 30·60·120fps 일치를 검증합니다.

`godot --path . --script res://preview_motion.gd --write-movie /절대/경로/preview.avi -- --verify-game`

모기 행동·밤별 목표·설치물 이동·에프킬라·창문 닫기권을 포함하는 웹 빌드입니다. 전기모기채는 접촉 시 짧은 따닥 소리를 냅니다.

쓰지 않는 3D·물리·네트워크·고급 GUI 기능을 제외한 Godot 4.7.2 전용 엔진을 사용합니다. 한글 글꼴·음향·현재 화면 효과는 유지합니다.

- `mosquito-night-web.zip`: 정적 웹 서버에 그대로 올릴 수 있는 게임 빌드와 라이선스
- `Source code (zip / tar.gz)`: 해당 빌드의 게임 코드·원본 이미지·오디오·검증 코드·재빌드 도구
- 빌드 안의 `build.json`: 게임 커밋·엔진 설정·파일 체크섬
- 빌드 안의 `size-report.json`: 파일별 원본 크기와 gzip-9 압축 추정 크기

소스에서 `python3 tools/export_web.py --output web-build`를 실행하면 동일 버전의 웹 엔진과 게임을 빌드합니다. 첫 빌드에는 개발 도구 다운로드와 엔진 컴파일이 필요하며, 이후 빌드에는 검증된 엔진 캐시를 재사용합니다.
